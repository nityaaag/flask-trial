# Student Portal - Flask Web Application

A simple Student Portal web application developed using **Python Flask**.

The application provides a basic academic information system with a home page and separate pages for About, Courses, and Contact information.

## Features

- Student Portal homepage
- Responsive web interface
- About page
- Courses page
- Contact page
- Navigation between pages
- Interactive buttons
- Mobile-friendly layout
- Flask routing
- Debug mode for development

## Technologies Used

- Python
- Flask
- HTML
- CSS
